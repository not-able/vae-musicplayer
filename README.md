# 许嵩音乐播放编排器

这是一个开源、本地优先的音乐播放软件骨架。项目围绕许嵩已发行歌曲的元数据进行专辑分类展示，后续会支持临时歌单、拖拽排序、播放次数控制和本地音频文件映射。

当前仓库只包含代码、文档、类型定义和少量占位 mock 数据。仓库不提供、不托管、不分发任何未经授权的音频、歌词、专辑封面或艺人图片。

## 技术栈

- Vite
- React
- TypeScript
- Vitest
- ESLint
- Prettier

后续可按需要接入 `dnd-kit`、`Zustand`、`Dexie` 和授权音源/第三方播放平台适配层。

## 本地启动

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run build
npm run test:run
npm run lint
npm run format:check
```

## 项目结构

```text
src/
  app/                  页面入口和应用布局
  components/           通用组件
  features/
    catalog/            专辑和歌曲目录
    playlist/           临时歌单骨架
    player/             播放器状态骨架
  data/
    catalog/            开发者维护的 mock 元数据
  types/                核心 TypeScript 类型
  utils/                可测试的领域工具函数
  tests/                测试配置和基础测试
docs/                   PRD 等项目文档
public/
  placeholders/         自制占位资源说明
```

## 版权约束

- 不要提交未经授权的音频文件。
- 不要提交未经授权的歌词文件。
- 不要提交未经授权的专辑封面、艺人照片或 MV 截图。
- 不要从商业音乐平台抓取并提交大段简介、评论、歌词或图片。
- 如果歌曲、专辑、曲序、发行日期等信息不确定，应使用占位样例或提醒开发者手动核对。

## 当前状态

当前已完成基础工程骨架、专辑目录和临时歌单核心状态流：

- 可选择专辑并查看按曲序排列的歌曲
- 通过按钮加入单曲或整张专辑，并支持把专辑拖入临时歌单
- 支持把目录歌曲拖入临时歌单、拖拽排序时在目标位置显示虚化占位，以及拖到歌单外移除
- 修改队列项播放次数、删除、清空和上下调整顺序
- 将临时歌单展开为实际播放序列
- 核心数据类型
- 少量占位 mock 数据
- 基础测试、lint、format 配置

真实播放器、本地文件映射和持久化尚未实现。
