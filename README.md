# 许嵩音乐播放编排器

这是一个开源、本地优先的音乐播放软件骨架。项目围绕许嵩已发行歌曲的元数据进行专辑分类展示，当前支持临时歌单、拖拽排序、播放次数控制，以及用户主动绑定本地音频后的真实播放。

当前仓库只包含代码、文档、类型定义和少量占位 mock 数据。仓库不提供、不托管、不分发任何未经授权的音频、歌词、专辑封面或艺人图片。

## 技术栈

- Vite
- React
- TypeScript
- Vitest
- ESLint
- Prettier

后续可按需要接入 `dnd-kit`、`Zustand`、`Dexie` 和授权音源/第三方播放平台适配层。

## 本地启动

```bash
npm install
npm run dev
```

常用命令：

```bash
npm run build
npm run test:run
npm run lint
npm run format:check
```

## 版权约束

- 不要提交未经授权的音频文件。
- 不要提交未经授权的歌词文件。
- 不要提交未经授权的专辑封面、艺人照片或 MV 截图。
- 不要从商业音乐平台抓取并提交大段简介、评论、歌词或图片。
- 如果歌曲、专辑或曲序等信息不确定，应使用占位样例或提醒开发者手动核对。

## 当前状态

当前已完成基础工程骨架、专辑目录、临时歌单和本地音频播放闭环：

- 可选择专辑并查看按曲序排列的歌曲
- 无需修改源码即可新增、编辑和恢复默认专辑、歌曲元数据
- 用户目录变更保存在当前浏览器的 `localStorage` 中
- 通过按钮加入单曲或整张专辑，并支持把专辑拖入临时歌单
- 支持把目录歌曲拖入临时歌单、拖拽排序时在目标位置显示虚化占位，以及拖到歌单外移除
- 修改队列项播放次数、删除、清空和上下调整顺序
- 将临时歌单展开为实际播放序列
- 临时歌单的顺序、重复实例和播放次数保存在当前浏览器的 `localStorage` 中
- 用户可为单曲绑定、更换或解绑自己选择的本地音频文件
- 可预览并确认导入一份已核对的许嵩正式专辑类目录（11 张专辑、111 首歌曲）；该导入只写入专辑和歌曲元数据，不下载、不绑定音频，也不会覆盖现有同名专辑
- 本地音频文件可按浏览器兼容模式保存副本，或在支持的浏览器中保存原文件句柄及其歌曲 ID 映射
- `HTMLAudioElement` 播放器支持播放、暂停、上一首、下一首、从头播放和自动推进
- 播放器与队列顺序、删除及 `repeatCount` 展开结果保持同步
- 刷新会恢复目录、临时歌单和音频绑定；播放器从安全的暂停状态开始，不恢复播放进度或自动播放
- 核心数据类型
- 少量占位 mock 数据
- 基础测试、lint、format 配置

目录元数据的范围、来源和更新规则见 [docs/metadata.md](docs/metadata.md)。

## 可选自托管元数据导入

“导入工具 → 导入远程元数据”默认关闭。用户可在弹窗中明确填写自己运行的 QQ Music API 服务地址，先测试连接，再手动搜索、查看专辑曲目与差异预览；只有确认后才会写入本地目录。也可在本地开发环境中用空的 `VITE_QQ_MUSIC_API_BASE_URL` 以外的值作为初始填写值，但仓库不会提供默认服务地址。

- 它只读取并规范化歌手、专辑、歌曲、曲序和时长等最小事实字段；不会请求或保存 Cookie、账号信息、歌词、封面、评论、下载链接、音频地址或原始响应。
- 远程查询不是应用启动、本地目录或本地播放的前置条件。服务不可用、上游超时、HTTP 错误、跨域拦截和结构变化都会保留已有本地目录并显示可理解提示。
- 自托管服务的代码许可证不等于音乐平台数据或内容的使用授权。使用者须自行确认上游服务与数据来源适用的许可、平台条款和使用范围；本项目不接入远程播放链接。

## 本地音频存储说明

- 音频只能由用户主动选择或授权访问；应用不会下载、上传或内置音频链接。
- 所有浏览器均可使用“选择音乐目录（复制文件）”。确认导入后，`File` 副本会保存到当前站点来源的 IndexedDB；这会占用浏览器本地空间，但不会写入仓库或可分发目录。
- Chrome、Edge 等提供 File System Access API 的浏览器会额外显示“选择目录（不复制，实验性）”。该模式只把每首歌的文件句柄保存到 IndexedDB，播放时再读取用户原文件，不复制整套音乐库。
- 句柄模式会在每次启动时检查读取权限。浏览器返回 `prompt` 或 `denied` 时，歌曲会明确显示“需要重新授权”，不会误报为可播放；用户可点击歌曲旁的“重新授权”，或重新选择文件绑定。浏览器仍可能撤销句柄或在隐私模式中清除站点数据。
- 目录导入区域会显示两种方式的已绑定数量和文件总大小；其中“原文件引用”的大小只用于帮助估算曲库规模，不占用浏览器的音频副本空间。
- 播放时只创建临时 `blob:` URL，并在切歌、解绑或关闭页面时释放。
- IndexedDB 受浏览器配额、清理策略、隐私模式和站点来源影响；更换域名、协议或端口后，原映射不可见。File System Access API 并非所有浏览器支持，故不能替代 File 副本回退；若需要稳定的跨平台磁盘访问，应评估 Tauri 等桌面方案。
