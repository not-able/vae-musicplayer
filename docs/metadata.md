# 目录元数据维护

## 当前已核对目录

应用提供一项需用户预览并确认的“许嵩正式专辑目录”导入，包含 11 张专辑类发行物和 111 首歌曲。它只新增当前目录中尚不存在的同名专辑，不覆盖已有专辑、歌曲或用户编辑，也不会删除占位目录。

该范围仅涵盖许嵩作为主艺人的专辑类发行物（按发行时间排序）。单曲、影视原声、精选合辑、重发版本及不同地区版本暂不混入此目录，避免同一作品重复展示；它们需要在单独任务中核对后再加入。

## 来源和许可边界

曲目名称和曲序在 2026-07-18 依据 [MusicBrainz 的许嵩艺人目录](https://musicbrainz.org/artist/ca084e75-0f3e-4c05-9f4d-b2714a8c8bb5) 逐张核对。MusicBrainz 将其核心数据库数据以 CC0 提供，具体边界见其[数据许可说明](https://musicbrainz.org/doc/About/Data_License)。

仓库只保留项目所需的艺人名、专辑名、歌曲名和曲序。不得加入或保存以下内容：

- 音频文件、播放链接、下载链接或任何远程音源 URL；
- 歌词、专辑封面、艺人图片、评论、长简介或原始 API 响应；
- Cookie、账号信息或第三方平台的鉴权数据。

导入目录不会绑定音频。播放仍要求用户主动为歌曲选择自己合法拥有的本地文件。

## 可选自托管 Provider

自托管 QQ Music API 仅可作为用户显式配置并手动触发的候选元数据来源。适配器只允许连接检测、搜索、歌手专辑、专辑详情和歌曲详情所需的最小请求；候选进入本地目录前必须展示差异并由用户确认。保存后只保留本地稳定 ID 与外部实体 ID 的映射，以及已经确认的最小事实字段。

Provider 默认关闭，服务超时、HTTP 错误、跨域限制、结构变化或空结果均不能阻塞已有本地目录和本地音频播放。服务地址可以由用户在界面填写，或以空值默认的 `VITE_QQ_MUSIC_API_BASE_URL` 提供初始值；不得在仓库内设置默认公网/本机地址、Cookie、账号信息或鉴权材料。

上游项目的代码许可证不等于音乐平台数据或内容授权。远程 Provider 不得调用或接入歌词、评论、封面、下载、Cookie 或任何播放链接接口，也不得将这些字段、原始响应或抓取快照持久化。

## 更新方式

新增或更正目录时应先从可复核来源收集事实字段，再人工确认发行范围、曲序和同名版本。不要根据记忆补全数据，也不要用数组下标作为实体 ID。远程元数据 Provider 只能由用户手动启用和查询，不能成为应用启动或本地播放的前置条件。
