1. 打开浏览器开发者工具的 Console、Network 和 Application 面板；在 Network 中开启 Preserve log。
2. 准备三首测试用目录歌曲，以下分别记为歌曲 A、歌曲 B 和歌曲 U。若当前目录只有两首歌，可通过现有“添加歌曲”界面新增一首仅用于本地验收的占位元数据，不填写真实歌词、路径或音源地址。
3. 为歌曲 A 绑定文件 A，为歌曲 B 绑定文件 B；歌曲 U 保持未绑定。
4. 确认界面分别显示两个文件名和“未绑定音频文件”。
