## 9. 重要决策速查

| 主题         | 已确认决策                                                                                 |
| ------------ | ------------------------------------------------------------------------------------------ |
| 本地音频     | 用户主动选择/绑定；不上传、不下载、不提交音频；播放只用本地 `File` 和临时 `blob:` URL      |
| 播放进度     | 做显示和拖动定位；不做倍速                                                                 |
| 音量         | 后续持久化音量和静音；不持久化播放状态、进度、Object URL 或事件 token                      |
| 歌单项点击   | 按精确 `queueItemId` 启动，之后沿当前歌单顺序和播放次数继续                                |
| 目录歌曲点击 | 只播放该曲一次，不加入、不重排、不持久化临时歌单                                           |
| QQ 元数据    | 查询、预览、确认后导入；内部稳定 ID 不使用外部 MID；不导入音源、歌词、封面、评论或原始响应 |
| 未匹配文件   | 可经在线候选创建本地目录，但必须人工确认，不能仅按文件名自动创建                           |
| 删除专辑     | 确认后级联歌曲、歌单项和本地音频绑定；不删除用户磁盘原文件                                 |
| 内置目录删除 | 本地隐藏，可恢复默认；恢复默认不恢复已删除歌单/音频绑定                                    |
